Cetti

メニューバーからワンクリックで、いつものウィンドウ配置を記憶・復元。
強大な権限不要、安全で軽量な macOS 窓整理ユーティリティ。

プライバシーと安全性を最優先した設計

Cetti は、他社製アプリを操作するための「アクセシビリティ権限」や画面内容を読み取る「画面収録権限」を一切要求しません。データはすべて Mac 内（ローカル）にのみ保存され、外部サーバーへの通信は一切行いません。

主な特長

⚡️ 丸暗記＆ワンクリック復元

作業中の画面レイアウト（各アプリのウィンドウ位置・サイズ）を「丸暗記」して保存。メニューバーやショートカットから一瞬でいつもの配置に戻せます。

🔒 強大なシステム権限不要

画面収録やアクセシビリティ権限は不要。Apple 標準の「ショートカット」アプリと連携することで、安全かつ確実にウィンドウを整列します。

🌐 完全ローカル・オフライン動作

ネットワーク通信機能（URLSession 等）を持たず、通信権限も要求しません。操作ログや設定が外部へ漏洩・送信されることは技術的に不可能です。

📐 ゾーン分割レイアウト

画面の2分割、3分割などのゾーン比率を自在に設定。マルチディスプレイ環境や外部モニターにも柔軟に対応します。

Cetti

Capture and restore your ideal window arrangements with a single click from the menu bar.
A lightweight, privacy-first window management utility for macOS without invasive permissions.

Designed with Strict Privacy and Security

Cetti never requests Accessibility permissions (UI manipulation of other apps) or Screen Recording permissions. All data remains exclusively on your local Mac, with absolutely zero network transmission.

Key Features

⚡️ One-Click Capture & Restore

Save your active multi-window layout as a "WorkSet" and restore it instantly via the menu bar popover or customizable global hotkeys.

🔒 No Invasive Permissions

Cetti relies on Apple's native Shortcuts app to move windows safely, avoiding dangerous Accessibility privileges and Screen Recording prompts.

🌐 100% Offline & Local

Contains no network communication code or network client entitlements. Technical impossibility of sending logs or user data externally.

📐 Smart Zone Splitting

Configure halves, thirds, and custom zone ratios for flexible multi-display and external monitor workflows.
